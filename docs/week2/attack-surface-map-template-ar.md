## مخطط التطبيق

```text
[تطبيق التدريب]
  +-- [مضيف/خدمة ضمن النطاق]
  |     +-- [مسار أو مجموعة وظائف]
  +-- [واجهة API ضمن النطاق]
        +-- [مسار/طريقة]
```

استبدل العناصر بين الأقواس بملاحظات الفريق فقط. لا تضف نطاقات طرف ثالث أو تخمينات غير متحققة.
