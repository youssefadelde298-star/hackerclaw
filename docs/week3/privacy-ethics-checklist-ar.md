# قائمة الخصوصية والأخلاقيات

استخدمها قبل الاختبار، قبل إرسال بيانات إلى نموذج، وقبل تسليم أي Finding.

## قبل الاختبار

- [ ] لدي تصريح مكتوب يحدد التطبيق والمضيفين والمسارات والحسابات المسموح بها.
- [ ] حددت ما هو خارج النطاق، وتجنبت الأنظمة التابعة لطرف ثالث والبيانات الحقيقية للمستخدمين.
- [ ] بدأت باختبارات يدوية صغيرة، غير مدمرة، وأوقفتها عند ظهور أثر غير متوقع.
- [ ] لم أفعل `--yolo`؛ مراجعة الإذن البشرية مفعلة.

## قبل استخدام نموذج

- [ ] حذفت كلمات المرور وCookies وBearer/API tokens والمفاتيح الخاصة والبيانات الشخصية من الطلبات والاستجابات والكود.
- [ ] إذا كان المزود سحابيًا، أرسلت بيانات وهمية أو منقحة فقط، وراجعت سياسة المؤسسة بشأن مشاركة البيانات مع ذلك المزود.
- [ ] لم ألصق مفتاح API في المحادثة أو في مستودع Git أو داخل طلب/استجابة محفوظة.
- [ ] أعلم أن مفتاح المزود يُحفظ محليًا في `~/.pentesterflow/config.json` ولا يُشفّر بواسطة HackerClaw؛ لا أشارك الملف وألغي المفتاح إذا انكشف.
- [ ] استخدمت نموذجًا محليًا عند التعامل مع بيانات لا يسمح بإرسالها إلى مزود خارجي.

## قبل اعتماد نتيجة

- [ ] أعدت الاختبار بنفسي داخل النطاق وشاهدت الاستجابة التي تدعم النتيجة.
- [ ] وثقت الطريقة والرابط والمعامل ومقتطف الاستجابة وخطوات إعادة الاختبار، بعد تنقيح الأسرار.
- [ ] فصلت ما لوحظ عن فرضيات AI، ولم أعتبر اقتراح النموذج أو مخرجات Scanner دليلًا.
- [ ] أبقيت الحالة `needs_human_review` حتى يراجع المختبر الدليل؛ لا يغيّرها AI إلى `human_verified`.
- [ ] طلبت موافقة بشرية قبل حفظ الملفين أو استيراد Finding إلى Burp.
- [ ] خزنت الأدلة في مجلد خاص بالمشروع، وحددت من يحتاج الوصول إليها ومدة الاحتفاظ بها.

## عند التسليم والتنظيف

- [ ] أرفقت الحد الأدنى اللازم من الأدلة، لا سجلات كاملة فيها بيانات غير لازمة.
- [ ] حذفت الملفات المؤقتة والحسابات/البيانات التي أنشأتها للاختبار وفق تعليمات المختبر.
- [ ] سجلت حدود الاختبار والأنظمة التي لم يتم التحقق منها، ولم أصفها بأنها سليمة.
