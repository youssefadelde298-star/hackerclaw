# مكتبة Prompts v1

## القوالب

- `recon-analysis-v1.md`: فرز جرد نقاط النهاية والطلبات المصرح بها دون إرسال طلبات.
- `finding-analysis-v1.md`: تحليل دليل HTTP منقح وإعداد مسودة Finding.
- `code-review-v1.md`: مراجعة الكود الذي يقدمه المختبر دون ادعاء أن المشكلة قابلة للاستغلال قبل التحقق.
- `report-drafting-v1.md`: إعداد تقرير من نتائج راجعها الإنسان فقط.

## قواعد الاستخدام

1. اكتب النطاق المصرح به والمسارات المحددة قبل التحليل.
2. احذف Cookies وTokens وكلمات المرور والبيانات الشخصية من المدخلات.
3. لا ترسل بيانات حساسة إلى مزود API سحابي؛ استخدم بيانات وهمية منقحة أو نموذجًا محليًا.
4. تعامل مع كل اقتراح على أنه فرضية. إعادة الاختبار وجمع الدليل واعتماد النتيجة مسؤولية المختبر.
5. يجب أن يطابق JSON الخاص بالـFinding `../schemas/finding-v1.schema.json`، وتظل حالته `needs_human_review` في خرج الذكاء الاصطناعي.
