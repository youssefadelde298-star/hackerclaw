# Prompt v1: صياغة التقرير

```text
اكتب مسودة تقرير أمني من النتائج المنقحة أدناه فقط.

النطاق وبيئة الاختبار:
[اكتب التطبيق المصرح به، الإصدار، والقيود]

النتائج:
[الصق JSON المنقح المطابق للمخطط]

استخدم فقط النتائج التي حالتها human_verified في الملخص التنفيذي. اعرض أي نتيجة أخرى في قسم منفصل بعنوان "تحتاج مراجعة بشرية". لا تخترع دليلًا أو CVSS أو أثرًا تجاريًا، ولا ترفع درجة الخطورة عن القيمة المدخلة.
احذف الأسرار والبيانات الشخصية. اكتب بلغة واضحة، وميّز الحقائق عن الافتراضات.

أخرج Markdown بالعناوين:
الملخص التنفيذي، النطاق والمنهجية، النتائج المؤكدة، نتائج تحتاج مراجعة بشرية، التوصيات، القيود.
لكل نتيجة مؤكدة أدرج العنوان والخطورة والطريقة والرابط ومقتطف الاستجابة المنقح والأثر وخطوات إعادة الاختبار والإصلاح.
```

لا تستخدم هذا القالب لإعلان نتيجة غير معاد اختبارها على أنها مؤكدة.
