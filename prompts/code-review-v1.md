# Prompt v1: مراجعة الكود

```text
راجع فقط الملفات والمقاطع البرمجية التي أرفقها المختبر من مستودع يملك تصريحًا لمراجعته.

السياق والنطاق:
[اكتب الجزء المصرح بمراجعته وإصداره إن كان معروفًا]

الكود المنقح:
[الصق المقاطع مع أسماء الملفات وأرقام الأسطر، بعد حذف المفاتيح والأسرار]

لا تنفذ الكود ولا تتصل بأي نظام. ميّز بين السلوك الظاهر في الكود والافتراضات التي تحتاج تحققًا وقت التشغيل. لا تسمّ النمط ثغرة مؤكدة دون مسار تأثير ودليل تشغيل.

أخرج JSON واحدًا بالمفاتيح:
reviewed_files, observations, candidate_issues, safe_validation, remediation, limitations.
لكل candidate_issue اذكر الملف/السطر، شرط الاستغلال، الأثر المحتمل، وما يلزم لإثباته يدويًا. إذا لم يظهر خلل مدعوم، أخرج قائمة candidate_issues فارغة.
```

مراجعة الكود تحدد مواضع تستحق الفحص؛ لا تحل محل إعادة اختبار بشرية في بيئة مصرح بها.
